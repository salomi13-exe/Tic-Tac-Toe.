Superstore Sales Data Analysis

Project Overview

This project focuses on analysing Superstore sales data using Python and Power BI to identify sales trends, profitability, and business insights.

Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
- Jupyter Notebook

Dataset

- 9,994 records
- 21 columns
- Sales, Profit, Discount, Category, Region and Customer information

Data Cleaning

- Removed duplicate records
- Handled missing values
- Removed incomplete records
- Converted Order Date into datetime format

Exploratory Data Analysis

- Category-wise Sales
- Region-wise Sales and Profit
- Monthly Sales Trends
- Discount vs Profit
- Segment-wise Profit
- Top 10 Profitable Sub-Categories
- Top Customers by Sales

Key Business Insights

- Technology is the most profitable category.
- Furniture has the lowest category-level profit.
- Copiers is the most profitable sub-category.
- Tables and Bookcases show negative profit.
- Discount and Profit have a weak negative correlation.

Power BI Dashboard

Created an interactive dashboard with:

- Total Sales
- Total Profit
- Total Orders
- Average Discount
- Sales and Profit charts
- Region and Category slicers

Project Files

- "Task_1_Sales_Data_EDA.ipynb"
- "Cleaned_Sales_Data.csv"
- "Task_1_Superstore_Dashboard.pbix"

Conclusion

This project demonstrates data cleaning, exploratory data analysis, data visualization, and interactive dashboard development to support data-driven business decisions.
