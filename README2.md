Task 2: Executive Sales & Profit Dashboard

Project Overview

An interactive Power BI dashboard built using Superstore Sales data to analyze business performance.

Key Features

- Total Sales KPI
- Total Profit KPI
- Profit Margin %
- YoY Sales Growth %
- Sales by Category
- Profit by Category
- Sales by Region
- Sales by Sub-Category
- Interactive Date, Category and Region slicers

Tools Used

- Microsoft Power BI
- DAX
- Power Query
