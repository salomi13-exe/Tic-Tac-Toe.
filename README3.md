Task 3: Customer Churn Analysis

Project Overview

This project focuses on analyzing customer churn using Python and data analysis techniques.

Dataset

- Dataset: Telco Customer Churn
- Total Customers: 7,043
- Total Columns: 21
- File: "telco_customer_churn.csv"

Key Findings

- Total Customers: 7,043
- Churned Customers: 1,869
- Overall Churn Rate: 26.54%

Analysis Performed

- Customer churn rate analysis
- Contract-wise churn analysis
- Payment method analysis
- Tenure group analysis
- High-risk customer identification
- Data visualization using charts and graphs

Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Project Files

- "Task 3_customer_churn_analysis.ipynb"
- "telco_customer_churn.csv"

Conclusion

The analysis helps understand customer churn patterns and identify customer groups that may require retention strategies.
